# VCU 三种运行模式切换指南

## 一、三种模式概述

| 模式 | 数据源 | CAN控制 | GPS | 适用场景 |
|------|--------|---------|-----|----------|
| **Simulink仿真** | Simulink模型 | Simulink内部处理 | 模拟 | 开发调试、无真实VCU硬件 |
| **Mock CAN模拟** | 模拟数据 | 软件Mock（无硬件） | 模拟 | 快速功能验证 |
| **真实硬件** | 真实传感器 | 真实CAN盒 | 真实 | 实际装车测试 |

---

## 二、配置文件对照表

修改 `main.py` 中以下三个开关：

| 配置项 | 行号 | Simulink仿真 | Mock CAN模拟 | 真实硬件 |
|--------|------|-------------|-------------|----------|
| `USE_SIMULINK` | ~102 | `"1"` | `"0"` | `"0"` |
| `MOCK_CAN` | ~96 | `False` | `True` | `False` |
| `MOCK_GPS` | ~114 | `"1"` | `"1"` | `"0"` |

### 环境变量快速切换

```bash
# Simulink仿真模式
set USE_SIMULINK=1
set MOCK_CAN=False
set MOCK_GPS=1

# Mock CAN模拟模式
set USE_SIMULINK=0
set MOCK_CAN=True
set MOCK_GPS=1

# 真实硬件模式
set USE_SIMULINK=0
set MOCK_CAN=False
set MOCK_GPS=0
```

## 三、各模式启动步骤

### 模式1：Simulink仿真

**端口分配：**
```
Simulink模型 → TCP 5000/5001 → Test.py → TCP 6000/7000 → car_server.py → WebSocket 8765 → AI端
```

**启动顺序（严格）：**
1. **先启动 Simulink 模型**（MATLAB 打开 `.slx` 文件并运行，模型作为 TCP 客户端连接 Test.py）
2. 启动 `Test.py`（中转服务，监听 5000/5001）
3. 启动 `car_server.py`（主服务，监听 8765 WebSocket）

**⚠️ 注意：**
- `simlink.py` 和 `car_server.py` 都占用 **8765 端口**，两者互斥，不能同时启动
- Simulink 模型必须先于 `car_server.py` 运行，否则 TCP 连接失败

### 模式2：Mock CAN模拟

**端口分配：**
```
Mock数据注入 → car_server.py → WebSocket 8765 → AI端
```

**启动步骤：**
1. 直接启动 `car_server.py`
2. Mock CAN 数据通过 `_mock_inject_thread()` 自动注入，无需额外启动其他服务

**特性：**
- `set_drv_mode_values()` 只修改全局变量，不构造实际 CAN 报文
- 没有真正的 0x512 报文发送，CANFDNET 不会打印报文内容
- GPS 仍然走模拟数据

### 模式3：真实硬件

**端口分配：**
```
真实CAN盒 + 真实GPS → car_server.py → WebSocket 8765 → AI端
```

**启动步骤：**
1. 连接 CAN 盒硬件和 GPS 模块
2. 启动 `car_server.py`
