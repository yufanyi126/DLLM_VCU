# CANFDNET — 连接 CAN 盒方法

> 硬件：ZLG 致远电子 CANFDNET 系列（CANFDNET-100 MINI / 200U / 400U / 800U / 200H / 400H / CANFDDTU-400）  
> 连接方式：TCP/IP 网络（网线直连或 WiFi）  
> PC 角色：TCP 客户端 → 主动连接 CANFDNET 服务器

---

## 一、硬件拓扑

```
┌──────────────┐         网线/WiFi          ┌──────────────────┐        CAN 总线        ┌──────────┐
│  你的 PC      │ ◄═══════════════════════► │  CANFDNET 硬件     │ ◄══════════════════► │  车辆 ECU │
│ (TCP Client)  │                           │  (TCP Server)     │                      │ (VCU 等) │
└──────────────┘                           └──────────────────┘                      └──────────┘
```

**PC 和 CANFDNET 必须在同一网络中能互相 ping 通。**

---

## 二、CANFDNET 硬件配置（先用 ZCANPRO）

在 PC 上运行代码之前，必须先用 ZLG 官方软件 **ZCANPRO** 把 CANFDNET 盒子的网络参数配好：

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| **工作模式** | TCP Server | 盒子被动等 PC 来连 |
| **本地 IP** | `192.168.1.253` | 盒子自己的 IP，固定不动 |
| **本地端口** | `1030` | 盒子的监听端口 |
| **波特率** | 500k / 1000k（按车辆实际） | CAN 总线通信速率 |
| **通道数** | 4 | CAN0 ~ CAN3 |

> 软件下载：[ZCANPRO / ZXDOC](https://manual.zlg.cn/web/#/314/12431)  
> 使用方法：[CANFDNET 系列使用说明](https://manual.zlg.cn/web/#/151/5352)

## 三、代码中的连接参数（`CANFDNET.py` 第 54~57 行 + 第 122~134 行）

```python
# 第 54~57 行 — 全局端口配置
work_port = ["1030"]       # 目标端口：CANFDNET 盒子的监听端口
local_port = ["1030"]      # 本地端口：PC Client 端不需要关心（默认即可）

# 第 122~134 行 — 连接参数设置
ret = zcanlib.ZCAN_SetValue(device_handle, "0/work_mode", "0")    # 0=PC作为客户端发起连接
ret = zcanlib.ZCAN_SetValue(device_handle, "0/work_port", "1030") # 目标端口，与盒子一致
ret = zcanlib.ZCAN_SetValue(device_handle, "0/ip", "192.168.1.253") # CANFDNET 盒子的 IP
```

### 参数对应关系

| 参数路径 | 代码中的值 | 对应盒子端的配置 | 作用 |
|----------|-----------|-----------------|------|
| `"0/work_mode"` | `"0"` | 盒子必须设为 TCP Server | `0`=PC做Client, `1`=PC做Server |
| `"0/work_port"` | `"1030"` | 盒子的本地端口 | 必须与盒子监听的端口一致 |
| `"0/ip"` | `"192.168.1.253"` | 盒子的 IP 地址 | **必须和电脑网口在同一网段** |
| `"0/set_device_tx_echo"` | `"1"` | — | 开启发送回显（自己发的报文也能收回来） |

## 四、连接步骤

### 第 1 步：硬件接线

1. 给 CANFDNET 盒子供电（DC 12V 或 USB 供电）
2. 用网线连接盒子和电脑（或接同一路由器）
3. CAN 总线接口接到车辆 OBD/CAN 接头

### 第 2 步：配通网络

1. 打开 ZCANPRO，连接到盒子，配置其 IP 为 `192.168.1.253`，端口 `1030`
2. 把电脑有线网卡 IP 配为 `192.168.1.x`（如 `192.168.1.100`），子网掩码 `255.255.255.0`
3. **在命令行验证**：
   ```bash
   ping 192.168.1.253
   ```
   能 ping 通就说明网络 OK

### 第 3 步：确认代码中的 IP/端口一致

确保 `CANFDNET.py` 第 55 行的 `work_port` 和第 132 行的 IP 地址与盒子配置一致。

### 第 4 步：设置 `MOCK_CAN = False`

在 `main.py` 中：
```python
MOCK_CAN = False   # 关闭 Mock 模式，使用真实 CANFDNET 硬件
```

### 第 5 步：运行程序

```bash
python main.py
```

正常输出应包含：
```
设备句柄: 1.
通道句柄: 1.
通道句柄: 2.
通道句柄: 3.
通道句柄: 4.
CAN 设备已启动，4通道接收中...
```

## 五、WiFi 连接（备选方案）

CANFDNET 插在路由器 LAN 口，PC 连同一个路由器的 WiFi，同样按上述步骤配置。

> ⚠️ WiFi 延迟波动比网线直连大，CAN 实时通信建议优先用网线。

## 六、常见问题

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| `打开设备失败` | `zlgcan` 库的 DLL 没找到 | 确保 `CANLan/` 目录下的 `.dll` 文件齐全 |
| 设备打开成功但收不到数据 | 网络不通 | ping 一下 `192.168.1.253` |
| 收不到特定 CAN ID | 通道映射表没配置 | 检查 `CAN_MSG_CHANNEL_MAP`（第 64 行） |
| `StartCAN fail` | 波特率不匹配 | ZCANPRO 中重设波特率 |
| 连接一直超时 | 防火墙拦截 | 放行端口 `1030` 或暂时关闭防火墙 |
