## RMS 字段说明
`rms` 为顶层独立字段（与 `route_summary`、`segments` 平级），表示**整个驾驶会话级别的驾驶画像**，基于最近约 300s 整车加减速/车速统计得出。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rms.style` | string | 驾驶风格，取值如 `normal`（平稳/标准）、`aggressive`（激进）等 |
| `rms.scenario` | string | 驾驶场景，如 `urban_smooth`、`suburban` 等 |

> 注意：`rms` 是全局画像，并非某一条路段的属性，因此不放在 `segments` 列表中，AI 上位机直接读取 `output_data["rms"]["style"]` 即可获取当前驾驶风格。
